# 启动器 Vue 控件

启动器使用 `@dsh-plugin/dsh-ui-components-vue` 的 `0.1.0-dev.45101238362` 版本，版本与完整性信息固定在 pnpm 锁文件中。

- `src/UiRoot.vue` 提供统一的主题、语言和浮层容器，同时覆盖主窗口与独立的终端、更新、启动进度窗口。
- `src/ui.ts` 按需注册启动器使用的 44 种控件，模板统一使用 `dsh-` 前缀。
- 按钮使用 `variant` 和 `sm/md/lg` 尺寸；原来的次要、文字及危险操作分别映射为对应语义变体。
- 页面消息使用 `useFeedback()`；命令式确认弹窗使用 `useDialog()`，继承当前主题与语言。
- 下载页的运行环境通过 `ToggleButtonGroup` 单选。选择「仅下载（不创建实例）」只安装本地版本，完成后可在「已安装版本」中查看，并在创建本地实例时直接复用。
- Arco 直接依赖仅用于简体中文、英文语言资源，组件和图标均从 DSH Vue 包导入。
- 样式从新组件包的 `style.css` 加载。主启动按钮使用 `radius="full"`，在双行高度下保持胶囊形状。
- 页面共用左上蓝、右下粉的渐变背景；深色采用纯黑底，浅色保留浅色底。侧栏与内容卡片采用半透明灰底、20px 圆角和 20px 背景模糊；侧栏四周留 20px，内容和菜单分别独立滚动。
- `PageScrollbar` 让内容滚动视口贴齐页面右侧和上下边缘；上下仍有内容时显示左右渐隐的滚动阴影，到达边缘自动隐藏。只在滚动、悬浮或拖动时显示无轨道滑块，并保留下载页滚动位置。Table 的横向滑块同样默认隐藏，在悬浮、滚动或拖动期间显示。
- 浏览器模式的新闻示例来自 `src/assets/news-preview.md`，包含标题、列表、提示块、表格、代码、公式、Mermaid、图片、折叠、剧透和脚注；原生启动器仍读取用户配置的新闻来源。
- Markdown 表格复用覆盖式横向滚动条，不额外撑高表格；提示块使用对应颜色的半透明磨砂底，代码块隐藏原生滚动条轨道和箭头。
- Markdown 普通引用使用无底色的左侧线，深色为 `#1F1F20`，浅色为 `#DDDDDD`；任务清单保留只读语义，两种状态均使用圆角矩形，选中时填充蓝色。高亮文字使用 45% 不透明度的圆角磨砂底，键盘按键使用 24px 高的紧凑灰色键帽。
- 文本域的焦点描边在控件内部绘制，避免被滚动容器裁切；AGENTS.md 预览边框和嵌入终端沿用 20px 卡片圆角。Toast 从上方滑入、向上滑出，并遵循减少动态效果设置。
- Windows 主窗口使用透明背景，在 20px 圆角外绘制前端阴影，最大化时移除阴影和透明留白。最小化、关闭按钮为圆形。下载页侧栏刷新按钮固定为 24px，刷新时各卡片显示贴合自身圆角的加载遮罩。

导航菜单的胶囊选中态、选择框的底色与边框、下拉选项状态、内层输入焦点和表格滚动阴影裁切由 `dsh-ui-components` 统一处理。联调时可构建并链接本地组件库。更新已发布的组件开发版时，同步更新依赖版本、锁文件和 `minimumReleaseAgeExclude`。

执行 `pnpm install --frozen-lockfile`、`pnpm build`、`pnpm test:market`、`pnpm test:network` 和 `pnpm test:compatibility-ui` 验证依赖、类型、构建及现有状态与解析规则。浏览器预览使用 `pnpm dev`，检查深浅主题、语言切换、下拉、提示、确认弹窗、表格与内部滚动。

组件库当前采用开发版本；升级时需重新核对其按钮、输入组合和浮层接口。原生 Tauri 文件选择与终端连接需在桌面构建中验收。
