# Web 实例通知

启动器在 Web 实例窗口未处于前台时，为计划待审、问题待回答和正常完成未查看的会话提供提醒。

设置页的“通知设置”包含三个独立复选框，默认全部启用：

- 系统提醒：显示“娱乐模式 · 计划待审”“娱乐模式 · 需要回答问题”或“娱乐模式 · 已完成”。点击卡片打开并聚焦对应实例。
- 声音提醒：每个新事件播放一次提示音，独立于系统提醒开关。
- 状态栏图标提醒：对应实例的系统托盘图标闪烁。关闭常驻实例托盘图标后，仍会在需要提醒时临时显示。

实例窗口处于前台时不弹出提醒、不播放声音、不闪烁。浏览器客户端在当前会话已打开并加载完成内容后，确认该会话已查看；其他会话和尚未加载的完成轮次继续保留未读提醒。问题已经回答、会话开始下一轮或实例退出时，清除相应的待提醒状态。相同事件不会重复提醒；限时问题超时后仍然可以回答时继续保留待处理状态。正常轮次结束后，当前代理和子代理全部空闲才发送完成提醒。

通知桥接通过启动参数中的临时补丁加载，监听宿主事件并原样继续问题回答流程。每次启动使用独立目录与事件标记，实例退出后清理目录。通知状态只保存在本次启动器进程内，历史会话不会在启动后重新弹出通知。已运行的实例需要重新启动后加载桥接。TUI 终端实例不在本功能范围内。

Windows 使用系统通知与 `dsh-launcher://notification` 协议打开实例，需使用已安装且注册该协议的启动器。macOS 和 Linux 使用本机通知服务处理点击；声音通过本机音频输出播放。

通知客户端编译产物不提交到仓库。`pnpm build` 和 `pnpm tauri-dev` 会先构建客户端；直接执行 Cargo 检查前，先运行 `pnpm build:bridge`。

验证时覆盖后台三类状态、前台抑制、重复事件、限时问题、多个会话的已读隔离、三个开关独立生效、托盘图标恢复、窗口关闭后继续接收，以及系统通知卡片点击聚焦。操作系统通知展示、实际声音输出和原生托盘效果需在对应桌面环境验收。
